# Diamond Intelligence Terminal

Diamond is an automated AI orchestration and local security dashboard designed to monitor local port registries, map system profiles, and communicate with secure local reasoning models.

## Core Functionalities
- **Automated Infrastructure Scans**: Real-time checking of active local network doors.
- **Local Model Orchestration**: Secure, offline parsing via integrated LLM backend scripts.
- **Isolated Sandbox Testing**: Built natively to run within local cybersecurity laboratory environments.

## System Dependencies
This application requires an active local large language model backend instance to process diagnostic scans.

1. Download and install the core framework layout client from the official site: https://ollama.com
2. Launch the background processing daemon loop engine inside your system terminal:
   ```bash
   ollama serve
   ```
3. Open a separate terminal window instance and download the primary reasoning model architecture:
   ```bash
   ollama run llama3
   ```

## Installation & Activation

1. Build and activate your isolated virtual environment sandbox directory:
   ```bash
   python3 -m venv diamond_env
   source diamond_env/bin/activate
   ```

2. Install the full Python toolkit package set required by Diamond:
   ```bash
   pip install streamlit ollama psutil pyttsx3 pyautogui numpy pillow
   ```

3. Initialize the Streamlit framework developer template skill blueprints:
   ```bash
   streamlit skills
   ```

4. Launch the graphical interface controller console layout panel:
   ```bash
   streamlit run Diamond_github.py
   ```
